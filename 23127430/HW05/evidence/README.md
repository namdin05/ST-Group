# Execution Evidence

Status: **NOT RUN**

## Hardware Evidence

Capture genuine evidence from the execution machine:

- `dxdiag` or an equivalent system report;
- hardware specification;
- hostname.

## Scenario Evidence

For each real scenario, capture the performance-testing tool together with backend-process resource usage using Task Manager, `htop`, Activity Monitor, or an equivalent tool.

Place evidence under `load/`, `stress/`, `spike/`, and `endurance/`. Do not fabricate screenshots or hardware/resource values.
