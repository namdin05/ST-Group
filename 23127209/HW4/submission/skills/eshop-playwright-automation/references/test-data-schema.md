# Test data contract

Each feature JSON file is an array with at least 12 records:

```json
{
  "id": "FR08-TC01",
  "description": "Checkout thành công",
  "preconditions": ["Đã đăng nhập"],
  "input": { "mode": "success" },
  "expected": ["HTTP 200", "Giỏ hàng rỗng"],
  "references": ["FR-08", "EC17", "BV2"]
}
```

- IDs are unique and start with the selected feature ID without the hyphen, e.g. `FR08-`.
- `description`, `expected`, and `references` are non-empty.
- Runtime-unique suffixes may be generated by fixtures; the logical input remains in the data file.
- Credentials and URLs come from environment-backed configuration, not records.

Browser projects are also data-driven:

```json
{
  "browsers": [
    { "name": "chromium", "device": "Desktop Chrome" },
    { "name": "firefox", "device": "Desktop Firefox" },
    { "name": "webkit", "device": "Desktop Safari" }
  ]
}
```

Playwright config must map these records to `devices`; feature specs must not hardcode browser names.
